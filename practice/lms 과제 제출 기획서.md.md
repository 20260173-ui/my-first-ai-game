# 게임 기획서: 컬러 블링커 (Color Blinker)

## 1. 기본 정보
- **게임 제목**: 컬러 블링커 (Color Blinker) (3가지 색의 적들을 파란색 플레이어가 점멸을 사용하며 피하는 게임이기 때문)
- **장르**: 캐주얼 아케이드 회피 게임 (Lateral Dodger)
- **기반 템플릿**: Pygame Dodger Template
- **개발 환경**: Python / Pygame

---

## 2. 게임 규칙 및 메커니즘

### 2.1 목표
- 화면 상단에서 떨어지는 다양한 패턴의 적들을 피하며 최대한 높은 점수를 획득하고 생존하는 것.

### 2.2 승리 및 패배 조건
- **승리 조건**: 최종 단계인 **5단계(Lv.5)** 진입 후 **30초 동안** 생존 시 클리어.
- **패배 조건**: 적과 충돌하여 플레이어의 **하트(체력) 3개**가 모두 소진되면 게임 오버.

### 2.3 조작 방법
| 키 입력 | 동작 |
| :--- | :--- |
| **좌/우 화살표 (←, →)** | 좌우 방향 이동 (속도 7) |
| **스페이스바 (Space)** | 점멸(Dash) 기능을 사용하여 순간 이동 (쿨타임 2초) |

---

## 3. 핵심 차별점 (Core Features)

### 3.1 이동 제약과 밸런스 조정
- 기존 상하좌우 이동 방식에서 **상하 이동을 과감히 삭제**하고 좌우 이동으로만 제한하여 긴박함을 더했습니다.
- 이동 제약을 보완하기 위해 기본 이동 속도를 **5에서 7로 상향** 조정하여 조작감을 개선했습니다.

### 3.2 점멸(Blink/Dash) 시스템
- 좌우 이동만으로는 피하기 어려운 밀집 상황을 탈출할 수 있는 **점멸 기능**을 추가했습니다.
- 점멸 시 약 **0.2초간 무적 판정**을 부여하여 전략적인 활용이 가능합니다.

### 3.3 특수 적 시스템
일반적인 적 외에 색상별로 고유한 패턴을 가진 적들을 배치했습니다.

| 적 종류 | 색상 | 특성 |
| :--- | :--- | :--- |
| **일반 적** | 빨간색 (Red) | 기본 속도로 직선 하강 |
| **대시 적** | 보라색 (Purple) | 화면 상단(y: 50~150)에서 플레이어 방향으로 **기습 점멸** 후 돌진 |
| **위험 적** | 검은색 (Black) | **Lv.1 고정 속도**로 느리게 이동하지만, 충돌 시 **하트 2개** 즉시 감소. 머리 위 **'Danger!'** 문구 표시 |

---

## 4. 난이도 및 스테이지 설계

### 4.1 단계별 구성
- 기존 3단계 구성을 **5단계**까지 확장하여 후반부 몰입도를 높였습니다.
- **Lv.1 ~ Lv.3**: 적의 속도와 생성 빈도가 일정하게 상승합니다.
- **Lv.4 ~ Lv.5**: 특수 적(보라색, 검은색)의 출현 비중이 높아지며 극한의 컨트롤을 요구합니다.

### 4.2 난이도 곡선
- 점수 20점마다 레벨이 상승하며, 레벨업 시 적 생성 타이머를 초기화하여 난이도 변화가 즉각적으로 체감되도록 설계했습니다.
- 최종 5단계는 **'서바이벌 모드'**로 전환되어 전용 생존 타이머가 작동합니다.
