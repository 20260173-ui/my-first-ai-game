# 6주차 실습 기록


## 사용한 에셋

- **이미지** (파일명: SpaceRage 파일 안에 있는 spritesheet, 출처: https://ravenmore.itch.io/space-shooter-assets-space-rage)
- **사운드**
  - 피격음: Asteroid 파일의 SFX 중 Shoot.wav 파일 사용 (출처: https://mianostudiogames.itch.io/asteroids-assets-pack)
  - BGM: https://freesound.org/people/Anurag19/sounds/709196/ 에서 m4a 파일을 받은 후 wav 파일로 변환하여 사용

---

## 사용한 AI 프롬프트

**1. 스프라이트 애니메이션을 플레이어 오브젝트에 적용**

> 지금까지 만들었던 게임 코드와 스프라이트 시트로 애니메이션을 만든 코드를 보내준 후, base64로 임베딩된 5개 이미지로 이루어진 애니메이션이 게임에서 플레이어가 조종하는 오브젝트에 출력되도록 해달라고 요청

- **AI 답변:** `pygame.draw.rect(...)`로 그리던 플레이어 오브젝트를 `screen.blit(walk_frames[anim_index], ...)`로 바꾸어, base64로 임베딩된 이미지가 작동되도록 변경해야 함
- **적용 결과:** 성공
- **문제점:** 플레이어가 이동한 방향에 따라 애니메이션이 달라지도록 요청하지 않았기 때문에, 이동 여부와 관계없이 항상 같은 애니메이션이 재생됨
- **개선 방법:** 애니메이션에 사용된 이미지들의 번호를 확인하고, 플레이어가 누른 버튼의 조작에 따라 출력 순서가 달라지도록 수정

---

**2. 이동 방향에 따른 애니메이션 분기 적용**

> 오른쪽으로 이동 시 4→5번째 이미지 순서로 출력, 왼쪽으로 이동 시 2→1번째 이미지 순서로 출력, 아무 행동도 하지 않을 때는 3번째 이미지를 유지하도록 요청

- **AI 답변:** 애니메이션 로직을 상태별(왼쪽, 오른쪽, 정지)로 분리하여 교체해야 함
- **적용 결과:** 성공

---

**3. 상대 경로 방식으로 BGM 및 사운드 이펙트 삽입**

> 실습 시간에 BGM과 사운드를 테스트할 때 사용한 파일을 제공한 후, 동일한 방식으로 상대 경로를 이용해 BGM과 사운드 이펙트를 삽입해 달라고 요청

- **AI 답변:** 제공된 파일의 내용을 그대로 삽입하면 적용 가능. 파일 경로만 본인 것으로 변경할 것
- **적용 결과:** 성공

---

**4. 피격 사운드 이펙트를 base64로 임베딩하여 파일 없이 실행**

> 위 코드와 동일한 환경에서, 피격 사운드 이펙트를 base64로 임베딩하고 `io.BytesIO`를 사용해 외부 파일 없이 실행되도록 요청

- **AI 답변:** `io.BytesIO`를 사용하여 피격음 사운드 이펙트를 base64로 코드에 직접 임베딩, 외부 파일 없이 실행되도록 처리
- **적용 결과:** 성공

---

## AI 답변이 도움이 된 것

처음 PNG 파일의 상대 경로를 설정할 때 어떻게 진행해야 하는지 감이 잡히지 않았으나, AI에게 질문한 후 자신의 파일 경로를 다시 검토한 결과 상대 경로로 이미지 파일을 삽입하는 데 성공할 수 있었다.

---

## AI 답변을 수정하거나 버린 것

스프라이트 시트 애니메이션을 적용할 때 AI가 base64 코드를 정상적으로 이해하지 못하는 경우가 있었다. 그래서 처음부터 다시 스프라이트 시트 코드를 받고, AI가 base64 코드를 읽다가 오류가 발생하지 않도록 해당 부분은 직접 붙여넣기로 진행하겠다고 미리 알린 뒤 코드를 받아야 했다.

---

## 적용 결과

- **잘된 것:** wav 파일을 이용해 사운드 이펙트와 BGM을 삽입하는 과정은 매우 수월하게 작업할 수 있었다.
- **어려웠던 것:** 처음 PNG 파일을 상대 경로로 삽입할 때 경로를 이해하지 못해 잠시 문제를 겪었다. 이후 base64로 임베딩한 스프라이트 시트 이미지를 AI가 이해하지 못해, 해당 부분을 직접 처리하기로 하고 진행하였다.
- **다음에 시도할 것:** 플레이어뿐만 아니라 떨어지는 적들에게도 스프라이트 시트로 애니메이션을 추가하여 더 완성도 높은 게임으로 만드는 과정을 진행할 것이다.
